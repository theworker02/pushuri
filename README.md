# pushuri

Push filesystem uri paths across POSIX and Windows conventions.

**Site:** https://theworker02.github.io/pushuri/

## Install / run

```bash
git clone https://github.com/theworker02/pushuri.git
cd pushuri
node src/cli.js
node --test
```
